Topic: Inheritance
Why does this exist?

To reuse common functionality and avoid duplicating code while allowing specialized classes to extend existing behavior.

Mental Model
Parent Class
      │
      ▼
Child Class

Child gets the parent's capabilities
and can add its own.

Think of it as:

Reuse first, then specialize.

Key Ideas
A child class inherits from a parent class.
The child automatically gets access to the parent's attributes and methods.
Inheritance promotes code reuse.
The child can add new behavior.
The child can also replace (override) inherited behavior (we'll study this next).
Syntax
class Animal:
    ...

class Dog(Animal):
    ...
Where will I see this?

PyTorch:

class MyModel(nn.Module):

Hugging Face:

class GemmaForCausalLM(PreTrainedModel):

Your SDK:

class CustomRunner(BaseRunner):
Common Mistakes
Thinking inheritance copies code.
Using inheritance when there isn't a true "is-a" relationship.
Forgetting that the child can extend the parent instead of rewriting everything.
Takeaway

Inheritance lets a class reuse common functionality from another class and specialize only what is different. This keeps frameworks like PyTorch and Hugging Face modular, reusable, and easier to maintain.
