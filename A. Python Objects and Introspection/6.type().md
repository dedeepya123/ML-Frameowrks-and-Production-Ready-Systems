Topic: type()
What is it?

type() returns the class from which an object was created.

Why does it exist?

To identify the kind of object you're working with.

Mental Model

Ask the object:

"Who created you?"

The answer is the class.

Key Ideas
Every object has a class.
type() tells you that class.
It's usually the first step when exploring unfamiliar objects.
Knowing the class helps you predict the object's behavior.
Examples
type(10)

→ int

type([1,2,3])

→ list

type("hello")

→ str

type(model)

→ Something like GemmaForCausalLM

Debugging
Why does this matter?

Before you can understand an object, you need to identify what kind of object it is. type() gives you that starting point.
