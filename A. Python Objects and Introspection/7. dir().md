Topic: dir()
What is it?

dir() lists the names of the members available on an object.

Why does it exist?

To help developers discover what an object exposes without needing to memorize the API.

Mental Model

dir() is like the table of contents or home screen of an object.

It shows what exists, not the details.

Key Ideas
dir() returns member names.
It includes both attributes and methods.
It does not execute methods.
It does not show attribute values.
It is one of the fastest ways to explore unfamiliar objects.
Example
type(model)

→ Tells you the class.

dir(model)

→ Shows available attributes and methods.

Where will I use this?
Hugging Face models
Tokenizers
PyTorch tensors
nn.Module
SDK objects
Response objects
Configuration objects
Why does this matter?

Instead of memorizing every API, you can ask the object what it exposes. This makes learning new frameworks and debugging much more efficient.

Think Like an ML Systems Engineer

Suppose tomorrow at work you receive this:

runner = sdk.create_runner(...)

Without reading any documentation, your first investigation could be:

type(runner)
dir(runner)

From those two lines alone, you already know:

What kind of object it is.
What capabilities it exposes.
What information it stores.

That's a disciplined, repeatable workflow you can apply to almost any Python codebase.
