Topic: model.state_dict()
Why does it exist?

To expose the model's persistent state in a portable format so it can be saved, inspected, or loaded later.

What is "state"?

The numerical values that define the model's behavior:

Parameters
Registered Buffers
Why a dictionary?

Because each piece of state has a unique hierarchical name.

Example:

encoder.layer1.attention.q_proj.weight
What does it return?

A mapping:

parameter_or_buffer_name
        ↓
Tensor
Included
✅ Parameters
✅ Registered Buffers
Not Included
❌ Normal Python attributes
❌ Configuration values
❌ Python methods
❌ Module code
Mental Model

Think of a model as:

Recipe (Python class)
        +
Ingredients after cooking (State)

The recipe tells you how to build the model.

The state tells you what the model has learned.
