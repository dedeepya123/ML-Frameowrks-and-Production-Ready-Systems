What is a dtype?

The numeric representation used to store each value in a tensor.

Why inspect dtypes?

To understand:

Memory usage.
Performance characteristics.
Training/inference configuration.
Compatibility with hardware.
Common dtypes
float32 – Common default precision.
float16 – Lower memory, often faster on supported GPUs.
bfloat16 – Widely used in modern deep learning.
int8 – Common for quantized inference.
Device vs Dtype

These are independent properties.

Property	Answers
Device	Where is the tensor stored?
Dtype	How is each value stored?

For example:

Embedding.weight

Device → cuda:0

Dtype → bfloat16

The device tells you where the data lives.

The dtype tells you how that data is represented.

Where we are now

At this point, you've built a strong inspection framework.

Given any nn.Parameter, you now know it has several important properties:

Parameter
│
├── Name
├── Shape
├── Number of values
├── Device
├── Dtype
├── requires_grad
└── Gradient (during training)

This is exactly how experienced PyTorch engineers think about parameters—not just as weights, but as objects with rich metadata.
