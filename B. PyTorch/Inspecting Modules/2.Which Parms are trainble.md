What makes a parameter trainable?

Its requires_grad flag.

True → Gradients are computed and the optimizer may update it.
False → The parameter stays fixed.
Frozen Parameters
Still part of the model.
Still used during inference and forward passes.
Still saved in state_dict().
Not updated during training.
Why freeze layers?
Faster training.
Lower memory usage for training.
Preserve previously learned knowledge.
Fine-tuning and transfer learning.
Connection to modern LLMs

Techniques like LoRA freeze most of the original model and train only a small number of additional parameters, making adaptation much more efficient.

One important connection

Notice how everything we've learned is starting to connect:

parameters() → gives you the Parameter objects.
named_parameters() → tells you which parameter you're looking at.
Each Parameter object has requires_grad.
The optimizer updates only parameters where requires_grad=True.
