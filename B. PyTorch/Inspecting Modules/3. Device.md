What is a device?

The hardware location where a tensor's data is stored and where operations on that tensor execute.

Examples:

CPU
CUDA GPU
Other accelerators (depending on the framework)
Does a model have a device?

Conceptually:

No.

Practically:

We say a model is on a device when all of its Parameters and Buffers are on that device.

Why inspect devices?

To:

Debug device mismatch errors.
Confirm model placement.
Verify deployment configuration.
Understand execution.
How does model.to(device) work?

It recursively moves all registered Parameters and Buffers to the specified device.

The Python object stays the same; the underlying tensor storage changes.

One important refinement

Notice how our understanding keeps getting richer.

A Parameter isn't just "a weight."

It has multiple pieces of information:

Parameter
│
├── Data
├── Shape
├── Device
├── Dtype
├── requires_grad
└── Gradient
