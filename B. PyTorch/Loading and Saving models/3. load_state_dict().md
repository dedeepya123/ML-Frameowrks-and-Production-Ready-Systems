What does load_state_dict() do?

It copies saved Parameters and Buffers into an existing model.

It does NOT
Create the model.
Replace Parameter objects.
Restore the optimizer.
Restore gradients.
Matching process

For each saved entry:

Match by name.
Verify compatibility (including shape).
Copy the tensor values into the existing Parameter or Buffer.
strict=True

Requires an exact match between the saved state and the current model.

strict=False

Loads matching entries and tolerates missing or unexpected keys. It is useful when architectures have been intentionally modified, but it does not bypass shape mismatches.
