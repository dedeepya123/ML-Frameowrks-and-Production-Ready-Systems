What does optimizer.state_dict() contain?
Per-parameter optimizer state
For Adam: moving averages (m, v), step count, etc.
Parameter group configuration
Learning rate
Weight decay
Betas
Epsilon
Other optimizer settings
Why save it?

To resume training from the exact optimization state.

Model vs Optimizer
Model	Optimizer
Stores learned parameters and buffers	Stores optimization history and hyperparameter configuration
model.state_dict()	optimizer.state_dict()
One beautiful design pattern

Notice how consistent PyTorch is:

nn.Module
        │
        ▼
state_dict()

Optimizer
        │
        ▼
state_dict()

Scheduler
        │
        ▼
state_dict()

Every major stateful object answers the same question:

"What is your persistent state?"

Then a checkpoint simply combines those states into one dictionary:

Checkpoint
│
├── model.state_dict()
├── optimizer.state_dict()
├── scheduler.state_dict()
├── epoch
└── metadata

That's elegant API design.
