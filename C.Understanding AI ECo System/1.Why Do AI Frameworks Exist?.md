# Module 1 - Lesson 1

## Why do frameworks exist?

Frameworks are created to solve repetitive engineering problems.

General pattern:

Repeated Work
        ↓
Standardize It
        ↓
Framework

Examples:

- NumPy → Numerical computing
- PyTorch → Deep learning primitives (Tensor, Autograd, nn.Module)
- Hugging Face → Pretrained models & model ecosystem
- PEFT → Parameter-efficient fine-tuning
- vLLM → Fast LLM inference
- QAIRT → Optimized inference on Qualcomm hardware

Important idea:

A framework usually **builds on top of** another framework instead of replacing it.

Example:

Application
    ↓
Hugging Face
    ↓
PyTorch
    ↓
Python
    ↓
Operating System
    ↓
Hardware

When learning a new framework, first ask:

1. What problem does it solve?
2. Why was it created?
3. What layer of the stack is it in?
4. What does it build on?
