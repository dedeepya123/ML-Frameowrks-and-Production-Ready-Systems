# Module 1 – Lesson 2

## The AI Software Stack

Applications
    ↓
AI Frameworks (Hugging Face, PEFT, Lightning...)
    ↓
Deep Learning Framework (PyTorch)
    ↓
Python
    ↓
Operating System & Drivers
    ↓
Hardware

### Responsibilities

- Hardware → Executes computations.
- OS & Drivers → Connect software to hardware.
- Python → General programming language.
- PyTorch → Tensors, autograd, neural network primitives.
- AI Frameworks → Higher-level abstractions for models, training, inference, or fine-tuning.
- Applications → End-user products.

### Learning Rule

When you discover a new framework, ask:

1. Where does it fit in the stack?
2. What problem does it solve?
3. What does it build on?
4. Does it replace an existing layer or extend it?
