A compact multi-head attention

Assume:

B = batch size
S = sequence length
H = number of heads
D = head dimension
hidden_size = H × D
``` python
class Attention(nn.Module):

    def __init__(self, hidden_size, num_heads):
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads

        self.q_proj = nn.Linear(hidden_size, hidden_size)
        self.k_proj = nn.Linear(hidden_size, hidden_size)
        self.v_proj = nn.Linear(hidden_size, hidden_size)
        self.o_proj = nn.Linear(hidden_size, hidden_size)

    def forward(self, x, position_ids=None, causal_mask=None):

        B, S, _ = x.shape

        # 1. Create Q, K, V
        q = self.q_proj(x)
        k = self.k_proj(x)
        v = self.v_proj(x)

        # 2. Split hidden dimension into heads
        q = q.view(B, S, self.num_heads, self.head_dim)
        k = k.view(B, S, self.num_heads, self.head_dim)
        v = v.view(B, S, self.num_heads, self.head_dim)

        # 3. Put heads before sequence dimension
        q = q.transpose(1, 2)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)

        # q, k, v: [B, H, S, D]

        # 4. Apply RoPE to Q and K
        q, k = apply_rope(q, k, position_ids)

        # 5. Compute attention scores
        scores = q @ k.transpose(-2, -1)

        # scores: [B, H, S, S]

        # 6. Scale
        scores = scores / math.sqrt(self.head_dim)

        # 7. Causal masking
        if causal_mask is not None:
            scores = scores + causal_mask

        # 8. Convert scores to attention probabilities
        weights = torch.softmax(scores, dim=-1)

        # 9. Retrieve information from V
        out = weights @ v

        # out: [B, H, S, D]

        # 10. Put heads back together
        out = out.transpose(1, 2)
        out = out.reshape(B, S, self.num_heads * self.head_dim)

        # 11. Final output projection
        out = self.o_proj(out)

        return out
```
Now let's read it like an engineer, rather than memorizing it.

1. Input
x

has:

[B, S, hidden_size]

For example:

B = 2
S = 5
hidden_size = 512
H = 8
D = 64

So:

x = [2, 5, 512]
2. Q/K/V projections
q = self.q_proj(x)
k = self.k_proj(x)
v = self.v_proj(x)

All remain:

[2, 5, 512]

Reason:

hidden_size → hidden_size
3. Split into heads
q.view(B, S, H, D)

becomes:

[2, 5, 8, 64]

Conceptually:

512
 ↓
8 heads × 64 dimensions

Then:

q.transpose(1, 2)

becomes:

[2, 8, 5, 64]

So now:

[B, H, S, D]

This is the representation we want for attention computation.

4. RoPE
q, k = apply_rope(q, k, position_ids)

Shape stays:

Q = [B,H,S,D]
K = [B,H,S,D]

RoPE changes the values inside Q and K, not their shape.

And importantly:

V

is untouched.

5. QKᵀ
scores = q @ k.transpose(-2, -1)

Before:

q = [B,H,S,D]

k = [B,H,S,D]

Transpose K's final two dimensions:

kᵀ = [B,H,D,S]

Therefore:

[B,H,S,D]
        ×
[B,H,D,S]
        ↓
[B,H,S,S]

For our example:

[2,8,5,64]
        ×
[2,8,64,5]

        ↓

[2,8,5,5]

This is the attention-score matrix for every head.

6. Scale
scores = scores / math.sqrt(self.head_dim)

This is:

D
	​

QK
T
	​


The shape doesn't change:

[B,H,S,S]
7. Causal mask
scores = scores + causal_mask

Conceptually:

before:

[2.1  4.3  1.2
 1.5  3.1  5.2
 0.8  2.4  1.9]

Mask:

[0   -∞  -∞
 0    0  -∞
 0    0   0]

Result:

[2.1  -∞  -∞
 1.5   3.1 -∞
 0.8   2.4  1.9]

Now future positions cannot receive probability.

8. Softmax
weights = torch.softmax(scores, dim=-1)

This is the key transformation:

scores
  ↓
softmax
  ↓
attention weights

Shape stays:

[B,H,S,S]

But meaning changes.

Before:

How relevant is each key?

After:

What fraction of attention should I give each key?

9. Multiply by V
out = weights @ v

Shapes:

weights = [B,H,S,S]

v       = [B,H,S,D]

Therefore:

[B,H,S,S]
        ×
[B,H,S,D]

        ↓

[B,H,S,D]

This is the actual information retrieval step.

Each query gets a weighted combination of the value vectors.

10. Combine heads

Currently:

out = [B,H,S,D]

But the rest of the Transformer expects:

[B,S,hidden_size]

So:

out = out.transpose(1, 2)

gives:

[B,S,H,D]

Then:

out.reshape(B, S, H * D)

gives:

[B,S,hidden_size]

For our example:

[2,5,8,64]
      ↓
[2,5,512]
11. o_proj

Finally:

out = self.o_proj(out)

Shape:

[2,5,512]

But now the important thing is that the eight heads have been mixed through a learned projection.

Then Attention.forward() returns that representation.

The key reasoning pattern

When you encounter a new model's attention class, don't ask:

"Why is this code so complicated?"

Ask:

Where are Q/K/V created?
Where are heads formed?
Where is positional information applied?
Where does [S,D] × [D,S] → [S,S] happen?
Where is causality enforced?
Where does [S,S] × [S,D] → [S,D] happen?
Where are heads recombined?
Where is the output projection?
