# Module 4 — Inside the Transformer Block

## Lesson 4 — Residual Connections

### 1. Core idea

A residual connection adds the original representation to a transformed version of it.

Mathematically:

y = x + F(x)

where:

x = original representation
F(x) = transformation
y = output

The original x is the residual/skip path.

---

## 2. Why residual connections exist

Residual connections allow a block to learn a modification/refinement to an existing representation rather than completely replacing it.

If:

F(x) ≈ 0

then:

y ≈ x

This provides an identity path through the network and helps make deep networks easier to optimize.

---

## 3. Generic structure

        x
        │
   ┌────┴────┐
   │         │
   │       F(x)
   │         │
   └───→ (+) ←
          │
          ▼
        x + F(x)

The residual path bypasses the transformation.

---

## 4. Transformer decoder block

A decoder block has two major residual sublayers.

### Attention sublayer

x1 = x + Attention(RMSNorm(x))

### MLP sublayer

x2 = x1 + MLP(RMSNorm(x1))

Overall:

x
 ↓
RMSNorm
 ↓
Multi-Head Attention
 ↓
+ x
 ↓
RMSNorm
 ↓
Gated MLP
 ↓
+ x1
 ↓
output

---

## 5. Where to save the residual

The residual must represent the input to the transformation being wrapped.

Correct:

residual = hidden_states

hidden_states = transformation(hidden_states)

hidden_states = residual + hidden_states

Conceptually:

output = x + F(x)

The residual is saved BEFORE the transformation.

---

## 6. Pre-normalization

Gemma uses a pre-normalization style.

Attention:

x
├────────────── residual path
│
└→ RMSNorm → Attention
                ↓
             + residual

MLP:

x1
├────────────── residual path
│
└→ RMSNorm → MLP
                ↓
             + residual

The residual path bypasses the normalization and transformation.

---

## 7. Multi-head attention and residuals

Attention internally changes representation shape.

Example:

hidden_states:
[B, S, H]

Q/K/V:
[B, heads, S, head_dim]

For example:

B = 2
S = 128
H = 3072
heads = 24
head_dim = 128

24 × 128 = 3072

Q/K/V:
[2, 24, 128, 128]

Attention eventually combines the heads and returns:

[B, S, H]

Residual addition occurs AFTER attention has returned to the decoder layer's hidden representation.

Therefore:

[B, S, H]
+
[B, S, H]
→
[B, S, H]

We do not add the residual directly to Q/K/V head tensors.

---

## 8. Residual addition is element-wise

Residual:

x + F(x)

means element-wise addition.

It is NOT concatenation.

Addition:

[B, S, H] + [B, S, H]
→ [B, S, H]

Concatenation would produce something like:

[B, S, 2H]

and is a different operation.

---

## 9. Residuals have no trainable parameters

A residual variable such as:

residual = hidden_states

is a tensor/data path.

It is not a trainable neural-network layer.

No parameters are associated with the residual connection itself.

---

## 10. How to identify residuals in source code

Look for the pattern:

residual = hidden_states

...

hidden_states = residual + hidden_states

The lines between these two points usually form the transformation wrapped by the residual connection.

For example:

residual = hidden_states

hidden_states = self.input_layernorm(hidden_states)
hidden_states = self.self_attn(hidden_states)

hidden_states = residual + hidden_states

means:

x1 = x + Attention(Norm(x))

---

## 11. General rule for new architectures

When reading a new model:

1. Identify the transformation/sublayer.
2. Identify its input representation x.
3. Check whether the architecture has an identity/skip path.
4. If yes, save x before the transformation.
5. Apply the transformation.
6. Add the original x back if the shapes are compatible.

Generic pattern:

x
├─────────────────────┐
│                     │
└→ Transform(x) → (+) │
                       │
                       ▼
                    output

Do not assume every layer has a residual.
Residual placement is an architectural decision.

---

## 12. Decoder-layer mental model

The Gemma decoder layer contains two residual blocks:

1. Attention residual:
   x1 = x + Attention(RMSNorm(x))

2. MLP residual:
   x2 = x1 + MLP(RMSNorm(x1))

Therefore:

Attention and MLP each refine the representation while preserving an identity path.

---

## 13. Code-reading skill

When seeing:

residual = hidden_states

ask:

"Where is this residual used?"

Find the later:

residual + hidden_states

Then identify everything between those points.

This reveals the logical transformation wrapped by the residual connection.
