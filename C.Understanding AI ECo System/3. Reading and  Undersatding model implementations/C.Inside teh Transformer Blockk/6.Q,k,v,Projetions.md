``` text
q = self.q_proj(x)
q = q.view(B, S, num_heads, head_dim)
q = q.transpose(1, 2)
```
you should now be able to explain it without memorizing:

"q_proj is one large learned projection that produces the Q representations for all heads together. Since hidden_size = num_heads × head_dim, the output can be reorganized into an explicit head dimension. The transpose changes [B,S,H,D] into [B,H,S,D], which is the layout convenient for computing attention independently across all heads."
