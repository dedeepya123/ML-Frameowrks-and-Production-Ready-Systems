# Module 4 — Inside the Transformer Block

## Lesson 7 — Attention Computation: QKᵀ → Softmax → V

## 1. Starting point

After Q/K/V projections and splitting into heads:

Q = [B, heads, S, D]
K = [B, heads, S, D]
V = [B, heads, S, D]

where:

B = batch size
heads = number of attention heads
S = sequence length
D = head dimension

---

## 2. Goal of attention

For every query token, determine how much attention it should give to every key token.

The result is an attention score for every:

query position × key position

Therefore the score matrix has shape:

[S, S]

With batches and heads:

[B, heads, S, S]

---

## 3. QKᵀ

K is transposed in its last two dimensions:

K:
[B, heads, S, D]

Kᵀ:
[B, heads, D, S]

Then:

Q @ Kᵀ

[B, heads, S, D]
        @
[B, heads, D, S]
        ↓
[B, heads, S, S]

Each element:

scores[i,j]

represents the similarity between:

query i

and:

key j

---

## 4. Dot product meaning

For one query q and key k:

q · k

= sum(q_dimension × k_dimension)

A larger dot product means the query and key are more aligned in the learned representation space.

---

## 5. Scaling

Raw attention scores are divided by:

sqrt(D)

So:

scaled_scores = QKᵀ / sqrt(D)

Purpose:

Keep the magnitude of logits under control before softmax and improve numerical behavior.

---

## 6. Causal masking

Gemma is a causal decoder.

A token cannot attend to future tokens.

For sequence length 4:

      key
      0  1  2  3
q 0  ✓  ✗  ✗  ✗
q 1  ✓  ✓  ✗  ✗
q 2  ✓  ✓  ✓  ✗
q 3  ✓  ✓  ✓  ✓

Forbidden positions are given a very negative value, conceptually -∞.

After softmax, those positions receive approximately zero probability.

---

## 7. Correct ordering

For causal attention:

QKᵀ
 ↓
scale
 ↓
causal mask
 ↓
softmax
 ↓
attention weights
 ↓
multiply by V

The mask is applied before softmax so forbidden positions receive zero probability.

---

## 8. Softmax

Softmax converts raw scores into normalized weights.

For one query:

scores:
[2.0, 1.0, 0.0]

softmax:

approximately:
[0.665, 0.245, 0.090]

The values sum to 1.

After softmax:

attention_weights[i,j]

means:

"How much weight should query i assign to key/value position j?"

---

## 9. Why softmax uses dim=-1

Attention weights have shape:

[B, heads, query_position, key_position]

The final dimension is the key position.

We want the attention probabilities for each query to sum to 1 across all allowed key positions.

Therefore softmax is applied over the last dimension.

---

## 10. Weighted aggregation of V

After softmax:

attention_weights:
[B, heads, S, S]

V:
[B, heads, S, D]

Compute:

attention_weights @ V

[B, heads, S, S]
        @
[B, heads, S, D]
        ↓
[B, heads, S, D]

For one query:

weights = [0.7, 0.2, 0.1]

output:

0.7V0 + 0.2V1 + 0.1V2

Therefore attention is a weighted aggregation of value vectors.

---

## 11. Three distinct stages

### Similarity

QKᵀ

Question:

"How relevant is key j to query i?"

### Attention weights

softmax(QKᵀ / sqrt(D))

Question:

"How much weight should each key receive?"

### Information aggregation

weights @ V

Question:

"What information should the query receive?"

These are different concepts.

---

## 12. Multi-head computation

All heads are represented in a tensor:

[B, heads, S, D]

The computation is vectorized.

Conceptually:

Head 0:
Q0K0ᵀ → weights0 → weights0V0

Head 1:
Q1K1ᵀ → weights1 → weights1V1

...

But implementations usually perform these simultaneously rather than using Python loops.

---

## 13. Output shape

Attention produces:

[B, heads, S, D]

Then heads are combined:

[B, heads, S, D]
        ↓ transpose
[B, S, heads, D]
        ↓ reshape
[B, S, heads × D]
        ↓
[B, S, hidden_size]

Then o_proj maps the combined representation back into the model's hidden space.

---

## 14. Complete attention pipeline

X
 ↓
q_proj / k_proj / v_proj
 ↓
Q / K / V
 ↓
reshape into heads
 ↓
[B, heads, S, D]
 ↓
QKᵀ
 ↓
scale
 ↓
causal mask
 ↓
softmax
 ↓
attention weights
 ↓
weights × V
 ↓
[B, heads, S, D]
 ↓
combine heads
 ↓
[B,S,hidden_size]
 ↓
o_proj
 ↓
attention output

---

## 15. Code-reading pattern

When seeing:

attn_weights = query_states @ key_states.transpose(...)

Think:

"Calculate query-key similarity."

When seeing:

attn_weights /= sqrt(head_dim)

Think:

"Scale the logits."

When seeing:

attn_weights += causal_mask

Think:

"Prevent attending to future tokens."

When seeing:

softmax(attn_weights, dim=-1)

Think:

"Convert scores into a probability distribution over key positions."

When seeing:

attn_output = attn_weights @ value_states

Think:

"Aggregate value information according to the attention weights."

---

## 16. Core mental model

Attention answers two questions:

1. Where should I look?
   → QKᵀ + softmax

2. What information should I take from there?
   → weighted sum of V

Therefore:

Attention(Q,K,V)

= softmax(QKᵀ / sqrt(D) + mask) V
