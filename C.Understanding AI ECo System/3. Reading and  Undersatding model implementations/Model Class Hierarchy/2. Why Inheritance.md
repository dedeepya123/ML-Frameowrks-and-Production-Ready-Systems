# Module 3 – Lesson 2

# Why Inheritance?

## Problem

Many model classes need the same behaviors.

Examples:
- Save checkpoints
- Load checkpoints
- Initialize weights
- Store configuration

Copying these methods into every class would create duplication.

---

## Solution

Use inheritance to share common behaviors.

Example hierarchy:

PreTrainedModel
    ↓
GemmaPreTrainedModel
    ↓
GemmaModel
    ↓
GemmaForCausalLM

---

## Responsibility by Layer

PreTrainedModel:
- Framework-wide behaviors.

GemmaPreTrainedModel:
- Gemma-specific shared behaviors.

GemmaModel:
- Transformer implementation.

GemmaForCausalLM:
- Language modeling task.

---

## Composition vs Inheritance

Composition:
- "Has-a" relationship.
- Example:
  GemmaForCausalLM has a GemmaModel.

Inheritance:
- "Is-a" relationship.
- Example:
  GemmaModel is a GemmaPreTrainedModel.

---

## Key Takeaways

- Use inheritance to share behavior.
- Use composition to assemble reusable components.
- Different hierarchy levels own different responsibilities.
- Build the architecture mentally before reading the code.
