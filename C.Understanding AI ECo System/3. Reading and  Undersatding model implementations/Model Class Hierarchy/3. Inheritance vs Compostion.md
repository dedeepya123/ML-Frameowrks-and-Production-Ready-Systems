# Module 3 – Lesson 3

# Inheritance vs Composition

## Important Rule

Never confuse:

- Inheritance hierarchy
- Object (composition) hierarchy

They describe different relationships.

---

## Inheritance

Purpose:
Share behavior.

Relationship:
IS-A

Example:

PreTrainedModel
    ↓
GemmaPreTrainedModel
    ↓
GemmaModel

and

PreTrainedModel
    ↓
GemmaPreTrainedModel
    ↓
GemmaForCausalLM

---

## Composition

Purpose:
Build larger objects from smaller reusable objects.

Relationship:
HAS-A

Example:

GemmaForCausalLM

├── GemmaModel

└── LM Head

---

## Responsibilities

GemmaModel:
- Produces hidden states.

GemmaForCausalLM:
- Uses GemmaModel.
- Converts hidden states to logits.

---

## Reading Strategy

For every class ask:

1. What does it inherit?
2. What objects does it own?

---

## Key Takeaways

- Inheritance shares behavior.
- Composition assembles functionality.
- Both are used together.
- Draw separate inheritance and composition diagrams when reading model code.
