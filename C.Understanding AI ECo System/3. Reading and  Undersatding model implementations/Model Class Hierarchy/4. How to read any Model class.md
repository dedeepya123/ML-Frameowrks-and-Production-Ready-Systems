# Module 3 — Lesson 4

# How to Read Any Model Class

## Reading Order

Never start with implementation.

Follow this order:

1. Purpose
2. Responsibility
3. Relationships
4. State
5. Behavior
6. Implementation Details

---

## Questions to Ask

### Purpose

Why does this class exist?

---

### Responsibility

What work belongs to this class?

---

### Inheritance

Who am I?

---

### Composition

What objects do I own?

---

### State

Which objects are created in __init__()?

Why do they belong here?

---

### Behavior

What sequence of operations happens in forward()?

---

### Inputs / Outputs

What enters?

What leaves?

---

### Relationships

Who calls this class?

Whose output does it consume?

---

### DL Connection

Which deep learning concept does this implement?

---

### Simplified Implementation

Could I implement a minimal version?

---

## Golden Rule

Understand the architecture before reading the implementation.
