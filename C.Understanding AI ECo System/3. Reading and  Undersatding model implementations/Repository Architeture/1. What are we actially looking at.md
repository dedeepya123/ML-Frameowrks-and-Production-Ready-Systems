# Module 1 — Lesson 1

# Understanding a Model Repository

## Mental Model

A pretrained model is not a single file.

It is a complete software package containing everything needed to reconstruct and use a trained neural network.

---

## Four Core Components

### 1. Configuration

Purpose:
Describe the architecture.

Examples:
- hidden_size
- num_hidden_layers
- num_attention_heads
- vocab_size

---

### 2. Model Code

Purpose:
Implement the neural network architecture.

Examples:
- Embedding
- Attention
- MLP
- Decoder Layer
- Forward pass

---

### 3. Weights

Purpose:
Store learned parameters from training.

Examples:
- Embedding weights
- Attention weights
- MLP weights
- Normalization weights

---

### 4. Tokenizer

Purpose:
Convert between human-readable text and model token IDs.

Contains:
- Tokenizer code
- Vocabulary
- Tokenization data

---

## Design Principle

Each component has a single responsibility:

- Configuration → Describe
- Code → Implement
- Weights → Learn
- Tokenizer → Preprocess

---

## Key Takeaways

- A model repository is a software package.
- Code and trained artifacts are intentionally separated.
- The repository contains everything needed to reconstruct a trained model.
- Understanding these responsibilities makes any model repository easier to navigate.
