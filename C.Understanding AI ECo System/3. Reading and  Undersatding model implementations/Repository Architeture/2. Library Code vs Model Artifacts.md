# Module 1 – Lesson 2

# Library Code vs Model Artifacts

## Library Code

Purpose:
Implement reusable behavior.

Examples:
- configuration_gemma.py
- modeling_gemma.py
- tokenization_gemma.py
- processing_gemma.py

Contains:
- Python classes
- Methods
- Algorithms
- Neural network implementation

Question it answers:
"How is this model implemented?"

---

## Model Artifacts

Purpose:
Provide model-specific data.

Examples:
- config.json
- model.safetensors
- tokenizer.json
- tokenizer.model

Contains:
- Configuration values
- Learned weights
- Vocabulary
- Tokenizer data

Question it answers:
"What values should this implementation use?"

---

## Relationship

Library Code
        │
        ▼
Creates model implementation
        │
Reads configuration
        ▼
Instantiates model
        │
Loads weights
        ▼
Ready-to-use model

---

## Key Takeaways

- Library code defines behavior.
- Model artifacts provide data.
- The same library implementation can support many different checkpoints.
- Separating implementation from data improves reuse, maintainability, and flexibility.
