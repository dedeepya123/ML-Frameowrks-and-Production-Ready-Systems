# Module 2 – Lesson 4

# from_pretrained() Lifecycle

## Goal

Reconstruct a trained model from a pretrained model repository.

---

## Lifecycle

1. User calls:
   AutoModel.from_pretrained(...)

2. Locate the model repository.

3. Read config.json.

4. Determine model_type.

5. Look up the corresponding implementation class.

6. Instantiate the model class.

7. Build the nn.Module hierarchy.

8. Read the checkpoint.

9. Load parameters using load_state_dict().

10. Return the ready model.

---

## Responsibilities

Configuration:
- Describes the architecture.

Library Code:
- Implements the architecture.

Checkpoint:
- Stores learned parameters.

AutoModel:
- Orchestrates reconstruction.

---

## Key Insight

The model structure is created **before** weights are loaded.

Weights do not define the architecture—they populate an already constructed architecture.

---

## Mental Model

Repository
    ↓
Read Configuration
    ↓

**from_pretrained()**
- orchestrates the reconstruction of a trained model by reading configuration metadata, selecting the correct implementation, constructing the nn.Module hierarchy, and loading the learned parameters into that hierarchy."

What does from_pretrained() actually do?"

A concise explanation is:

It locates the model repository, reads the configuration to determine the architecture, uses that information to instantiate the correct model class from the Transformers library, loads the trained weights into the model using load_state_dict(), and returns a fully initialized model ready for use.
