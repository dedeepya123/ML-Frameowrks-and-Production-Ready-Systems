# Module 1 – Lesson 4

## How to Analyze Any AI Framework

Whenever you encounter a new framework, ask:

### 1. What problem does it solve?
Understand the recurring engineering problem that motivated its creation.

### 2. Where does it fit in the AI stack?
Identify whether it is a:
- Model library
- Training framework
- Fine-tuning framework
- Inference framework
- Deployment tool
- Evaluation tool
- Experiment tracking tool

### 3. What does it build on?
Most AI frameworks build on existing layers such as PyTorch and Python.

### 4. What abstractions does it introduce?
Identify its main objects rather than memorizing APIs.

Examples:
- PyTorch → Tensor, Parameter, Module
- Hugging Face → AutoModel, AutoTokenizer, AutoConfig

### 5. What work does it automate?
Ask:
"If this framework didn't exist, what manual work would I have to do?"

This reveals the framework's real value.

## Mental Model

Framework = Automation of repetitive engineering work built on top of existing abstractions.
