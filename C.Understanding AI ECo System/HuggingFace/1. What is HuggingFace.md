# Module 2 – Lesson 1

## What is Hugging Face?

Hugging Face is an **AI ecosystem**, not a single library.

It contains multiple libraries and services.

Main components:

### Transformers
Purpose:
- Standard model implementations.
- Pretrained models.

### Hub
Purpose:
- Store and share models, datasets, and related files.

### Datasets
Purpose:
- Standard dataset loading and processing.

### Tokenizers
Purpose:
- Fast and standardized text tokenization.

### Evaluate
Purpose:
- Standard evaluation metrics.

### Diffusers
Purpose:
- Diffusion models (e.g., image generation).

### Accelerate
Purpose:
- Simplify distributed and multi-device training.

## Mental Model

Your Code
    ↓
Hugging Face Library
    ↓
PyTorch
    ↓
Python

Hugging Face does **not** replace PyTorch.
It builds on top of it by standardizing common ML workflows.
