# Module 2 – Lesson 2

## Why does the `transformers` library exist?

Researchers publish models with different:

- Code structures
- APIs
- Checkpoint formats
- Configurations

This makes reuse difficult.

The `transformers` library standardizes how engineers interact with different Transformer models.

### Common engineering tasks

- Load model
- Save model
- Read configuration
- Run inference (`forward`)
- Load tokenizer
- Use pretrained checkpoints

### Important idea

The library standardizes **interaction**, not **implementation**.

Different architectures (BERT, Gemma, Llama, T5, etc.) still have different internal designs, but they expose consistent concepts to users.

### Mental Model

Research Model
        ↓
Common Hugging Face Abstractions
        ↓
Consistent Engineering Experience
