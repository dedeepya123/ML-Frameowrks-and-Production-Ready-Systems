# Module 2 – Lesson 3

## Internal Organization of the `transformers` Library

The library is organized by **model architecture**.

Conceptually:

transformers/
    models/
        bert/
        gemma/
        llama/
        t5/
        vit/
        ...

Each model package contains components with different responsibilities:

- configuration → Architecture metadata.
- modeling → PyTorch `nn.Module` implementation.
- tokenization → Text preprocessing.
- processing → Multi-modal preprocessing (when needed).

### Key Idea

The public API is simple, but the internal implementation is modular.

### Mental Model

Transformers
    ↓
Model Folder
    ↓
Configuration
Model
Tokenizer
Processor

This organization makes the library scalable and maintainable.
