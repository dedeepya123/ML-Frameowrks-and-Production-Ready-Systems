# Module 2 – Lesson 4

## What is a pretrained model?

A pretrained model is **not just weights**.

It is a package containing everything needed to reconstruct and use a trained model.

### Main Components

1. Configuration
   - Defines the architecture.
   - Example:
     - hidden_size
     - num_hidden_layers
     - num_attention_heads
     - vocab_size

2. Weights
   - Learned parameters from training.
   - Loaded into the architecture.

3. Tokenizer
   - Converts text ↔ token IDs.
   - Contains vocabulary and tokenization rules.

4. Metadata
   - Model card
   - License
   - Documentation
   - Usage information

### Mental Model

Configuration
      ↓
Construct Model
      ↓
Load Weights
      ↓
Ready Neural Network

Text
      ↓
Tokenizer
      ↓
Token IDs
      ↓
Model
      ↓
Token IDs
      ↓
Tokenizer
      ↓
Text

### Key Idea

A pretrained model is a **complete package**, not just a `.pt` file.
