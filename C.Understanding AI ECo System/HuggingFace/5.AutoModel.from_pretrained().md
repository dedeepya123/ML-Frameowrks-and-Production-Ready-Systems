# Module 2 – Lesson 5

## How `AutoModel.from_pretrained()` Works

### Step 1
Locate the pretrained model repository.

### Step 2
Download the required files (configuration, weights, etc.).

### Step 3
Read the configuration.

### Step 4
Determine the model type.

### Step 5
Select the appropriate model class.

Example:

config.model_type
        ↓
Gemma
        ↓
GemmaModel

### Step 6
Construct the PyTorch `nn.Module`.

### Step 7
Load pretrained weights using `load_state_dict()`.

### Step 8
Return the ready-to-use model.

## Important Ideas

- `AutoModel` is **not** a neural network.
- It is a dispatcher/factory that selects the correct model class.
- The returned object is a normal PyTorch `nn.Module`.
- `from_pretrained()` loads pretrained weights; it does not train the model.
