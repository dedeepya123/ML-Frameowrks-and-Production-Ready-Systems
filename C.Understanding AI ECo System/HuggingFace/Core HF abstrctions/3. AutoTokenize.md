# AutoTokenizer

## Why does it exist?

Neural networks operate on tensors, not raw text.

A tokenizer converts human-readable text into the token IDs expected by the model.

Different models may use different tokenization algorithms and vocabularies.

AutoTokenizer automatically loads the correct tokenizer for a pretrained model.

---

## Responsibilities

Tokenizer:
- Convert text → token IDs
- Convert token IDs → text
- Manage vocabulary
- Handle special tokens
- Apply tokenization rules

Model:
- Accept token IDs
- Convert IDs to embeddings
- Perform neural network computation
- Produce predictions

These are separate responsibilities.

---

## Key Takeaways

- Models do not understand raw text.
- Tokenizers are independent objects with their own data and logic.
- The tokenizer used during inference should match the tokenizer used during training.
- AutoTokenizer is a factory that returns the correct tokenizer implementation.

**Why does AutoTokenizer exist?**
Neural networks cannot process raw text; they operate on token IDs. Different models are trained with different tokenization schemes and vocabularies. AutoTokenizer automatically loads the correct tokenizer for a pretrained model, ensuring the text is converted into the exact token IDs that the model expects.
