# ModelOutput

## Why does it exist?

Modern models produce multiple outputs:

- Logits
- Hidden states
- Attention weights
- Loss
- Past key/value cache
- Others

Returning a single tensor or tuple becomes difficult to understand and extend.

ModelOutput provides a structured object for returning model results.

---

## Why not return a tuple?

Tuple:

outputs[2]

Problems:
- Poor readability
- Depends on position
- Hard to extend

---

## Why not return a dictionary?

Dictionary:

outputs["logits"]

Better than tuples, but a structured object provides:
- Attribute access
- Clear schema
- Better documentation
- Easier extension

---

## Responsibilities

Model:
- Perform computation

ModelOutput:
- Organize and expose computation results

---

## Key Takeaways

- ModelOutput is not part of the neural network.
- It has no parameters or layers.
- It is a structured container for model outputs.
- Different tasks may use different ModelOutput classes.
- It improves readability and API maintainability.


**Why doesn't Hugging Face just return a tensor?**

A good answer is:

Modern models can produce many outputs besides the primary prediction, such as hidden states, attention weights, losses, and caches. Returning a structured ModelOutput object makes the API more readable, easier to extend, and less error-prone than using tuples or dictionaries.
