# Module 6 — Lesson 3: Quantized Matrix Multiplication

## Core Equation

X ≈ sx × Xq
W ≈ sw × Wq

Therefore:

Y = XW

becomes approximately:

Y ≈ sx × sw × (XqWq)

---

## INT8 × INT8

Conceptually:

INT8 input
×
INT8 weight
↓
wider accumulation
↓
typically INT32
↓
scale/requantization
↓
output

Why wider accumulation?

Products and sums can exceed INT8 range.

---

## GEMM

GEMM = General Matrix-Matrix Multiplication.

Linear layers are fundamentally matrix multiplications.

Model:

Linear
↓
MatMul
↓
GEMM
↓
quantized GEMM
↓
NPU matrix kernel

---

## Important Distinction

Mathematical level:
Y ≈ sx × sw × (XqWq)

Operator level:
QuantizedMatMul

Kernel level:
INT8 GEMM

Hardware level:
NPU matrix/integer compute unit

---

## Scaling

The mathematical result needs quantization scales.

Runtime may:
- apply scaling separately
- fuse scaling with GEMM
- requantize to another datatype
- convert to FP16/FP32

Exact implementation is runtime/kernel dependent.

---

## INT4

W4A16 does NOT uniquely specify implementation.

Possible strategies:
- unpack/dequantize
- specialized low-bit kernel
- hardware-native packed INT4 computation

Therefore:

Logical precision ≠ exact physical implementation.

---

## Systems Connection

Quantized GEMM can reduce:
- weight bytes
- memory traffic
- potentially compute cost

But actual speed depends on:
- NPU hardware support
- kernel quality
- memory bottleneck
- fusion
- conversion overhead
