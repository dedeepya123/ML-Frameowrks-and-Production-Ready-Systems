# Module 4 — Lesson 5: Context Length vs KV Memory

## Core Relationship

KV memory:

KV ∝ B × L × N × Hkv × Dh × dtype_bytes

Therefore:

Context length ↑
→ KV memory ↑ linearly

## Important

Context includes both:

- prompt tokens
- generated tokens

L_final ≈ prompt + generated tokens

## Two Effects of Longer Context

1. Capacity:
   KV memory per request ↑

2. Decode cost:
   KV data accessed ↑
   Attention work ↑

Therefore:

L ↑
→ memory capacity pressure ↑
→ memory bandwidth pressure ↑
→ attention work ↑

## Serving Impact

For fixed available memory:

Context ↑
→ KV/request ↑
→ maximum concurrency ↓

## Important Distinction

Model context capability:
"What context length can the architecture handle?"

Deployment capability:
"What context length can the hardware/runtime handle efficiently?"

These are different questions.

## Reasoning Rule

When long-context performance degrades, inspect:

- KV memory
- KV bandwidth
- attention computation
- memory capacity
- concurrency
- runtime/kernel behavior

Do not assume the bottleneck without profiling.
